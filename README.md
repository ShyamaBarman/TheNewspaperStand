# TheNewspaperStand
A simple yet powerful console-based application built with Core Java, JDBC, and MySQL to help manage newspaper subscribers, payments, and deliveries efficiently

Overview
Managing newspaper subscriptions manually can be messy and error-prone. This project digitizes the process by allowing vendors to:
Register new subscribers
Track monthly payments
Record daily deliveries
Identify unpaid customers instantly

Features
✔️ Add and manage subscriber details
✔️ Record monthly payments
✔️ Track newspaper deliveries
✔️ View unpaid subscribers for any month
✔️ Menu-driven console interface
✔️ Secure database operations using Prepared Statements

🛠️ Tech Stack
Java (Core Java)
JDBC (Java Database Connectivity)
MySQL
